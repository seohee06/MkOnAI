[중간고사 대체 과제]

첫 독립 가구 맞춤형 예산 및 필수 가전 관리 웹앱: "룸메이트온 (One-Room Way)" 기획서

작성자: 서수정

1. 프로젝트 개요 및 기획 배경 (개선된 방향)

기존 아이템(공유 자전거, 배달 팟, 뻔한 캘린더 등)과의 차이점 (중요)

기존 기획의 한계: 시중에 이미 대기업 서비스(배달의민족, 토스, 카카오맵 등)가 장악하고 있거나, 일상에서 굳이 웹앱으로 만들 실효성이 떨어져 기획의 타당성(왜 직접 개발해야 하는가?)을 설명하기 어려웠음.

개선된 기획 (본 아이템): 20대 사회초년생 및 대학생들이 생애 처음 독립할 때 겪는 '정보 과부하와 예산 통제 불능 상태(페인 포인트)'를 정확히 타겟팅함. 종합 인테리어 플랫폼은 쇼핑 유도가 너무 심하고 엑셀은 번거롭다는 점에 착안하여, 이사 D-Day 역산 관리와 품목별 예산 CRUD(생성·수정·삭제)를 결합한 미니멀 전용 웹앱으로 차별화함.

2. 시스템 구성도 (System Architecture)

본 프로젝트는 복잡한 외부 API 연동 없이 프론트엔드와 경량 백엔드(Supabase/Local Storage) 간의 데이터 흐름에 집중하여, 혼자서 구현하기에 가장 안정적인 구조로 설계되었습니다.

[사용자 (Client: Web Browser)] - HTML5 / CSS3 / JavaScript (UI & Client-side Logic) · D-Day 카운트다운 계산기 · 예산 합산 및 실시간 잔액 연산 (JavaScript Sum Algorithm) · 로컬 상태 및 체크박스 토글 제어 (REST API / Fetch) [백엔드 데이터베이스 (Supabase / Database)] - Table 1: users (사용자 기본 예산 정보 - 총 예산, 이사 목표일) - Table 2: items (구매 품목 데이터 - 품목명, 카테고리, 예상가, 실구매가, 상태) - Table 3: checklists (부동산/입주청소 체크리스트 상태 값)

3. 화면 설계서 (와이어프레임)

[화면 1] 메인 대시보드

  • 이사 예정일과 D-Day
  • 전체 예산 / 남은 예산
  • 현재까지 실제로 지출한 금액
  • 구매 예정 품목 예산 및 바로가기 버튼

[화면 2] 품목 및 예산 관리

  • 품목명과 카테고리 설정
  • 예상 가격과 실제 구매가 관리
  • 구매 상태 (고민중, 장바구니, 구매완료)
  • 품목 추가·수정·삭제 기능

[화면 3] 계약 및 입주 체크리스트

  • 계약 전 확인 항목
  • 입주 전 확인 항목
  • 체크 완료 여부 토글 및 전체 완료 항목 수 표시

[화면 4] 최종 지출 내역

  • 실제 지출 합계 및 남은 예산 확인
  • 구매 완료된 품목 목록 및 영수증 프리뷰
  • 지출 내역 복사 버튼
